🚀 ЗА 5 МИНУТ НАСТРОИТЬ ЭКСПОРТ В GOOGLE ТАБЛИЦЫ

═══════════════════════════════════════════════════════════════════
ШАГ 1: GOOGLE CLOUD CONSOLE (3 минуты)
═══════════════════════════════════════════════════════════════════

1. Перейти: https://console.cloud.google.com/
2. Создать проект: "Telegram Bot"
3. Включить APIs:
   - Google Sheets API
   - Google Drive API
4. Создать Service Account:
   - APIs & Services → Credentials → Create Credentials
   - Service Account → telegram-bot → Editor
5. Скачать credentials.json:
   - Keys → Add Key → JSON

═══════════════════════════════════════════════════════════════════
ШАГ 2: GOOGLE ТАБЛИЦА (1 минута)
═══════════════════════════════════════════════════════════════════

1. Создать: https://docs.google.com/spreadsheets/
2. Название: "Telegram Bot - Рефералы"
3. Share → вставить email из credentials.json → Редактор
4. Скопировать URL таблицы

═══════════════════════════════════════════════════════════════════
ШАГ 3: НАСТРОЙКА БОТА (1 минута)
═══════════════════════════════════════════════════════════════════

1. Положить credentials.json в папку с ботом
2. Добавить в .env:
   GOOGLE_SHEETS_URL=https://docs.google.com/spreadsheets/d/ВАШ_ID/edit
3. Установить:
   pip install gspread google-auth
4. Перезапустить бота

═══════════════════════════════════════════════════════════════════
✅ ГОТОВО!
═══════════════════════════════════════════════════════════════════

Теперь:
- Рефералы автоматически экспортируются каждые 5 минут
- В Google Таблице появится лист "Рефералы" с данными
- Можно экспортировать вручную через админ-панель

═══════════════════════════════════════════════════════════════════
📊 ЧТО ЭКСПОРТИРУЕТСЯ В ТАБЛИЦУ:
═══════════════════════════════════════════════════════════════════

Лист "Рефералы":
- ID пригласившего
- Username пригласившего
- Имя пригласившего
- Сколько оплативших у него
- ID приглашенного
- Username приглашенного
- Имя приглашенного
- Оплатил ли подписку (✅/❌)
- Дата приглашения

═══════════════════════════════════════════════════════════════════
🎯 КАК РАБОТАЕТ СИСТЕМА:
═══════════════════════════════════════════════════════════════════

1. Пользователь: "👥 Пригласить друга"
   → Получает ссылку: https://t.me/бот?start=ref_123456789

2. Друг переходит по ссылке
   → Связь сохраняется в БД

3. Друг оплачивает подписку
   → Пригласившему начисляется 10% бонус

4. Все данные экспортируются в Google Таблицы автоматически
