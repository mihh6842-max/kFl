## 🎯 Как работает реферальная система {#как-работает}

### Схема работы:

```
1. Пользователь А нажимает "👥 Пригласить друга"
   ↓
2. Получает ссылку: https://t.me/ваш_бот?start=ref_123456789
   ↓
3. Отправляет ссылку другу (Пользователь Б)
   ↓
4. Пользователь Б переходит по ссылке → /start ref_123456789
   ↓
5. Бот сохраняет связь в таблицу referrals:
   referrer_id: 123456789 (Пользователь А)
   referred_id: 987654321 (Пользователь Б)
   ↓
6. Пользователь А получает уведомление о новом реферале
   ↓
7. Если Пользователь Б оплачивает подписку:
   - Пользователю А начисляется 10% от суммы
   - Пользователь А получает уведомление о бонусе
```

### Система уровней:

| Уровень | Приглашено | Награда |
|---------|-----------|---------|
| 🌱 Новичок | 0-2 | Пригласи друзей! |
| 🔥 Активист | 3-4 | Скидка 10% на подписку |
| ⭐ Амбассадор | 5-9 | Скидка 15% на подписку |
| 💎 VIP | 10-19 | Скидка 20% + бонусный контент |
| 👑 Легенда | 20+ | Максимальные привилегии |

## 🔧 Настройка Google Sheets для экспорта {#настройка-google-sheets}

### Шаг 1: Создание Service Account в Google Cloud

1. **Перейдите в Google Cloud Console:**
   - Откройте: https://console.cloud.google.com/
   - Войдите с вашим Google аккаунтом

2. **Создайте новый проект:**
   - Нажмите на выпадающий список проектов вверху
   - Выберите "Новый проект"
   - Название: "Telegram Bot Referrals" (или любое другое)
   - Нажмите "Создать"

3. **Включите Google Sheets API:**
   - В меню слева: "APIs & Services" → "Library"
   - Найдите "Google Sheets API"
   - Нажмите "Enable" (Включить)

4. **Включите Google Drive API:**
   - Вернитесь в "Library"
   - Найдите "Google Drive API"
   - Нажмите "Enable"

5. **Создайте Service Account:**
   - В меню слева: "APIs & Services" → "Credentials"
   - Нажмите "Create Credentials" → "Service Account"
   - Заполните:
     - Service account name: `telegram-bot`
     - Service account ID: `telegram-bot` (автозаполнится)
   - Нажмите "Create and Continue"
   - Role: выберите "Editor" (Редактор)
   - Нажмите "Done"

6. **Скачайте credentials.json:**
   - Найдите созданный Service Account в списке
   - Нажмите на него
   - Перейдите в "Keys" (Ключи)
   - "Add Key" → "Create new key"
   - Тип: **JSON**
   - Нажмите "Create"
   - Файл `credentials.json` скачается автоматически

7. **Установите credentials.json в проект:**
   ```bash
   # Скопируйте скачанный файл в папку с ботом:
   cp ~/Downloads/credentials.json C:\Users\admin\Desktop\KLS_bot\
   ```

### Шаг 2: Создание Google Таблицы

1. **Создайте новую таблицу:**
   - Откройте: https://docs.google.com/spreadsheets/
   - Нажмите "Создать" → "Пустая таблица"
   - Название: "Telegram Bot - Рефералы"

2. **Получите URL таблицы:**
   ```
   Пример: https://docs.google.com/spreadsheets/d/1ABC...XYZ/edit
                                                    ^^^^^^^^^^^
                                                    Это ID таблицы
   ```

3. **Дайте доступ Service Account:**
   - Нажмите "Настройки доступа" (Share) в правом верхнем углу
   - Вставьте email Service Account (из credentials.json):
     ```
     telegram-bot@ваш-проект.iam.gserviceaccount.com
     ```
   - Роль: **Редактор**
   - Снимите галочку "Уведомить пользователя"
   - Нажмите "Готово"

### Шаг 3: Настройка бота

1. **Откройте `.env` файл:**
   ```bash
   nano .env
   ```

2. **Добавьте URL таблицы:**
   ```env
   GOOGLE_SHEETS_URL=https://docs.google.com/spreadsheets/d/ВАШ_ID_ТАБЛИЦЫ/edit
   ```

3. **Сохраните файл** (Ctrl+O, Enter, Ctrl+X)

### Шаг 4: Установка зависимостей

```bash
pip install gspread google-auth
```

### Шаг 5: Проверка работы

1. **Запустите бота:**
   ```bash
   python bot.py
   ```

2. **Проверьте логи:**
   ```
   ✅ Начальный экспорт рефералов: Экспортировано 0 рефералов
   🔄 Периодический экспорт рефералов запущен (каждые 5 минут)
   ```

3. **Откройте Google Таблицу:**
   - Должен появиться лист "Рефералы" с заголовками
   - Данные будут обновляться автоматически каждые 5 минут

## 🗄️ Структура базы данных {#структура-бд}

### Таблица `referrals`:

```sql
CREATE TABLE referrals (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    referrer_id INTEGER,        -- ID пригласившего
    referred_id INTEGER,        -- ID приглашенного
    created_at INTEGER,         -- timestamp приглашения
    UNIQUE(referrer_id, referred_id)
);
```

### Таблица `users` (дополнительная колонка):

```sql
ALTER TABLE users ADD COLUMN referral_earnings REAL DEFAULT 0;
```

## 🔌 API функции {#api-функции}

### Основные функции:

```python
# Получить количество рефералов
count = await get_referral_count(user_id)

# Получить реферальную ссылку
link = await get_referral_link(user_id)

# Получить награды и уровень
rewards = await get_referral_rewards(user_id)
# Возвращает: {'count': 5, 'level': '⭐ Амбассадор', ...}

# Получить список рефералов
referrals = await get_referral_list(user_id, limit=50)
# Возвращает: [(username, name, created_at, subscription_until), ...]

# Начислить бонус за оплату
await reward_referrer_for_payment(referred_id, amount)
```

### Экспорт в Google Sheets:

```python
# Импорт модуля
import google_sheets

# Экспорт рефералов
success, message = await google_sheets.export_referrals_to_sheet(
    spreadsheet_url="ВАШ_URL"
)

# Экспорт всех данных (пользователи + рефералы + платежи)
success, message = await google_sheets.export_all_data(
    spreadsheet_url="ВАШ_URL"
)
```

## 🐛 Troubleshooting (Решение проблем)

### Ошибка: "Ошибка подключения к Google Sheets"

**Решение:**
1. Проверьте что файл `credentials.json` существует
2. Проверьте что Service Account email добавлен в таблицу
3. Проверьте что включены Google Sheets API и Google Drive API

### Ошибка: "Permission denied"

**Решение:**
- Дайте Service Account доступ к таблице с ролью "Редактор"

### Рефералы не сохраняются

**Решение:**
1. Проверьте что таблица `referrals` создана:
   ```bash
   sqlite3 data/bot.db "SELECT * FROM referrals LIMIT 5;"
   ```
2. Проверьте логи бота на ошибки

### Экспорт не работает

**Решение:**
1. Проверьте переменную `GOOGLE_SHEETS_URL` в `.env`
2. Проверьте логи:
   ```bash
   tail -f логи_бота
   ```
