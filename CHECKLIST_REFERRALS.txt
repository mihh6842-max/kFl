⚠️ ЧАСТЫЕ ОШИБКИ:

1. "Ошибка подключения к Google Sheets"
   → Проверить credentials.json

2. "Permission denied"
   → Добавить Service Account в таблицу

3. Рефералы не сохраняются
   → Проверить логи бота

4. Экспорт не работает
   → Проверить GOOGLE_SHEETS_URL в .env

5. Данные не обновляются
   → Перезапустить бота

📞 ПОЛЕЗНЫЕ КОМАНДЫ:

# Проверить количество рефералов
sqlite3 data/bot.db "SELECT COUNT(*) FROM referrals;"

# Топ-5 пригласивших
sqlite3 data/bot.db "SELECT referrer_id, COUNT(*) as cnt FROM referrals GROUP BY referrer_id ORDER BY cnt DESC LIMIT 5;"

# Конверсия в оплату
sqlite3 data/bot.db "SELECT
    COUNT(*) as total,
    SUM(CASE WHEN u.subscription_until > strftime('%s','now') THEN 1 ELSE 0 END) as paid
FROM referrals r
JOIN users u ON r.referred_id = u.user_id;"

# Посмотреть логи экспорта
tail -f логи_бота | grep "экспорт"
