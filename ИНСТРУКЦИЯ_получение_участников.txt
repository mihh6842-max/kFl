📋 ИНСТРУКЦИЯ: Как получить список всех участников канала

════════════════════════════════════════════════════════════════

ШАГ 1: Получите API_ID и API_HASH
────────────────────────────────────────────────────────────────
1. Откройте в браузере: https://my.telegram.org/apps
2. Войдите с вашим номером телефона (получите код в Telegram)
3. Создайте приложение:
   - App title: любое название (например "Channel Members")
   - Short name: любое короткое имя (например "members")
   - Platform: Desktop
4. Скопируйте:
   - api_id (это число, например: 12345678)
   - api_hash (это строка, например: "1234567890abcdef1234567890abcdef")

════════════════════════════════════════════════════════════════

ШАГ 2: Вставьте данные в скрипт
────────────────────────────────────────────────────────────────
1. Откройте файл: get_all_members.py
2. Найдите строки 16-17:
   API_ID = None
   API_HASH = None

3. Замените на ваши данные:
   API_ID = 12345678  # БЕЗ кавычек!
   API_HASH = "1234567890abcdef1234567890abcdef"  # В кавычках!

4. Сохраните файл

════════════════════════════════════════════════════════════════

ШАГ 3: Запустите скрипт
────────────────────────────────────────────────────────────────
1. В командной строке выполните:
   python get_all_members.py

2. При первом запуске скрипт попросит:
   - Номер телефона (в формате +7XXXXXXXXXX)
   - Код из Telegram
   - Возможно пароль 2FA (если установлен)

3. После авторизации скрипт:
   ✅ Покажет всех участников канала
   ✅ Сохранит список User ID в файл: channel_members_ids.txt

════════════════════════════════════════════════════════════════

ШАГ 4: Используйте список ID
────────────────────────────────────────────────────────────────
1. Откройте файл: channel_members_ids.txt
2. Скопируйте все User ID
3. В боте: Админ-панель → "💰 Установить цену 1111₽"
   → "✏️ Установить по списку"
4. Вставьте скопированные ID
5. Готово! Всем участникам канала установлена цена 1111₽

════════════════════════════════════════════════════════════════

⚠️ ВАЖНО:
- API данные можно использовать многократно
- Сессия сохраняется (второй раз номер вводить не нужно)
- Скрипт безопасен, использует официальное Telegram API
