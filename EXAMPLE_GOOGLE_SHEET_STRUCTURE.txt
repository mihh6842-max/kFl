📊 ОБЪЯСНЕНИЕ КОЛОНОК:

1. ID - порядковый номер записи
2. Пригласивший ID - Telegram User ID пользователя, который пригласил
3. Пригласивший Username - @username пригласившего
4. Пригласивший Имя - Имя пригласившего из профиля
5. Оплативших у него - Сколько всего его рефералов оплатили подписку
6. Приглашенный ID - Telegram User ID приглашенного пользователя
7. Приглашенный Username - @username приглашенного
8. Приглашенный Имя - Имя приглашенного
9. Оплатил подписку - ✅ Да или ❌ Нет (есть ли активная подписка)
10. Дата приглашения - Когда произошло приглашение

💡 ИСПОЛЬЗОВАНИЕ ДАННЫХ:

1. Анализ эффективности:
   - Кто приглашает больше всех
   - Какая конверсия в оплату

2. Награды лучшим:
   - Топ-3 пригласивших
   - Бонусы за активность

3. Выявление проблем:
   - Низкая конверсия = нужно улучшить онбординг
   - Много приглашений, но мало оплат = проблемы с ценностью продукта

4. Экспорт для маркетинга:
   - Списки активных промоутеров
   - Рассылки с благодарностью

🎯 ДОПОЛНИТЕЛЬНО В ТАБЛИЦЕ МОГУТ БЫТЬ ЛИСТЫ:

- История всех платежей
